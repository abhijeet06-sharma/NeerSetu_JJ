# NeerSetu v6

Changes: normal-browser resilience, v6 service-worker cache, compact mobile header, deterministic demo history, and final-sensing water-quality wording.

## Important
- No cloud service or subscription is required.
- HTTP/LAN mode can display the PWA and use local storage.
- Real Web Bluetooth requires a secure browser context (HTTPS or localhost); this is a browser security requirement, not a NeerSetu subscription.
- Existing IndexedDB telemetry is not intentionally deleted by the service-worker update.
